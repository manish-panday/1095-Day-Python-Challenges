Python Coding Challenge: Movie Ticket Eligibility System
Background

A movie theater is introducing a new ticketing system.

To watch a movie, a customer must meet certain age requirements. If they are under the required age, they can still watch the movie only if they are accompanied by a parent.

Your task is to build this eligibility checker.

Requirements

Write a Python program that asks the user for:

Customer's full name
Customer's age
Whether they are accompanied by a parent (yes or no)

Store each value in a variable.

Eligibility Rules

Use logical operators (and, or, not) to determine the result.

Rule 1

If the customer is 18 or older, they are allowed to watch the movie.

Status:

Allowed
Rule 2

If the customer is under 18 but is accompanied by a parent, they are also allowed.

Status:

Allowed (With Parent)
Rule 3

Otherwise,

Status:

Not Allowed
Example 1
Input
Name: Manish
Age: 20
Parent: no
Output
========== MOVIE TICKET ==========

Customer: Manish
Age: 20

Parent Present: No

Status: Allowed

==============================
Example 2
Input
Name: Manish
Age: 15
Parent: yes
Output
========== MOVIE TICKET ==========

Customer: Manish
Age: 15

Parent Present: Yes

Status: Allowed (With Parent)

==============================
Example 3
Input
Name: Manish
Age: 14
Parent: no
Output
========== MOVIE TICKET ==========

Customer: Manish
Age: 14

Parent Present: No

Status: Not Allowed

==============================
