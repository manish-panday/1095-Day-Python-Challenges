Concept Explanation
The Modulo % Operator

The % operator gives you the remainder after division.

For example:

10 % 2

Result:

0

Because:

10 ÷ 2 = 5 remainder 0

But:

7 % 2

gives:

1

because:

7 ÷ 2 = 3 remainder 1

Therefore:

number % 2 == 0

means the number is even.

And:

number % 2 != 0

means the number is odd.

Warm-up Example
number = int(input("Enter a number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

If the user enters:

8

Output:

Even
