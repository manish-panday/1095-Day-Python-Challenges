Python Coding Challenge: School Library Membership Checker
Background

A school library is introducing a new membership system.

Not every student is allowed to borrow books. The library has rules based on membership status and overdue books.

Your job is to create a program that determines whether a student is allowed to borrow a book.

Requirements

Write a Python program that asks the user to enter:

Student's full name
Are you a library member? (yes / no)
Do you have any overdue books? (yes / no)

Convert both yes/no answers to lowercase before checking them.

Borrowing Rules
Rule 1

If the student is a library member and has no overdue books:

Status: Allowed to Borrow
Rule 2

If the student is not a library member:

Status: Membership Required
Rule 3

If the student is a member but has overdue books:

Status: Return Overdue Books First
Example 1
Input
Enter your full name: Manish Panday
Are you a library member? yes
Do you have overdue books? no
Output
========== LIBRARY STATUS ==========

Student: Manish Panday

Library Member: Yes
Overdue Books: No

Status: Allowed to Borrow

====================================
Example 2
Input
Enter your full name: Manish Panday
Are you a library member? no
Do you have overdue books? no
Output
========== LIBRARY STATUS ==========

Student: Manish Panday

Library Member: No
Overdue Books: No

Status: Membership Required

====================================
Example 3
Input
Enter your full name: Manish Panday
Are you a library member? yes
Do you have overdue books? yes
Output
========== LIBRARY STATUS ==========

Student: Manish Panday

Library Member: Yes
Overdue Books: Yes

Status: Return Overdue Books First

====================================
