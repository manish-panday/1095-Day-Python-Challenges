Concept Explanation

Suppose a user enters:

   manish panday

There are unnecessary spaces around the name.

Python can clean it:

name = name.strip()

Now:

manish panday
.lower()

Converts everything to lowercase:

country = "NEPAL"

print(country.lower())

Output:

nepal

Useful when comparing user input:

if answer.lower() == "yes":
.upper()

Converts everything to uppercase:

name = "manish"

print(name.upper())

Output:

MANISH
.title()

Capitalizes the first letter of each word:

name = "manish panday"

print(name.title())

Output:

Manish Panday
len()

Counts the number of characters:

password = "python123"

print(len(password))

Output:

9

Spaces are also counted as characters.

Warm-up Example
name = input("Enter your name: ")

name = name.strip()
name = name.title()

print(f"Welcome, {name}!")

If the user enters:

   manish panday

the program outputs:

Welcome, Manish Panday!
What's happening?
User Input
    ↓
"   manish panday   "
    ↓
.strip()
    ↓
"manish panday"
    ↓
.title()
    ↓
"Manish Panday"
Today's Challenge
Student Registration Validator

You are building a simple student registration system.

The program should collect basic student information and validate it before accepting the registration.

Requirements

Ask the user for:

Full name
Email address
Country
Age
Step 1 — Clean the Name

Remove unnecessary spaces from the beginning and end of the name.

Then format the name using .title().

For example:

Input:
   manish panday

Output:
Manish Panday
Step 2 — Validate the Name

The name must contain at least 3 characters.

If the name is too short:

Status: Invalid Name
Step 3 — Validate Email

For today's beginner-level validation, check whether the email contains:

@

and:

.

For example:

manish@gmail.com

Valid

But:

manishgmail.com

Invalid

Step 4 — Format Country

Convert the country into title case.

For example:

nepal

becomes:

Nepal
Step 5 — Validate Age

The student must be between:

13 and 100

If the age is outside this range:

Status: Invalid Age
Registration Rules

Your program should determine one final status.

If the name is invalid:
Invalid Name
Otherwise, if the email is invalid:
Invalid Email
Otherwise, if the age is invalid:
Invalid Age
Otherwise:
Registration Successful

Common Mistakes

Watch out for:

Forgetting .strip().
Checking the original name instead of the cleaned name.
Using or when you actually need and.
Forgetting that spaces count when using len().
Forgetting to convert the country with .title().
Accepting an email without @ or ..
Printing different copies of the same receipt.
Mixing up = and ==.
